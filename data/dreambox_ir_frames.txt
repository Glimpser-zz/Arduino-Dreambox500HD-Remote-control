Dreambox DM500HD - IR frames sent by the remote, per key (reference)
======================================================================

One key press is sent as a series of PAIRS. Each pair = header frame + key frame.

  Header frame (same for every key):  0x0B3F441A
  Order of pairs for one press:
    1) pair with the DOWN frame
    2) pairs with the REPEAT frame, one every 118 ms while the key is held
    3) pair with the UP frame
  Pause between header frame and key frame: 13.17 ms
  Pause between pairs while held: 80.4 ms;  before the UP pair: 13.26 ms

Frame word layout (32 bits, 8 hex digits, sent most significant nibble first):
  0 C F 3 K K 0 0   (hex digits left to right)
  C  = check digit, chosen so that the sum of all 8 hex digits is a multiple of 16
  F  = flags: 0 = key down, 8 = repeat, 9 = key up
  3  = constant
  KK = key code in hex (the Code column below, in hex)

Verified against frames captured from the original remote:
  key 0:  down 0x0D030000, repeat 0x05830000, up 0x04930000
  key 10: down 0x03030A00
Tested on the real box with the Arduino sender: key 32 (Menu).
All other frames are computed with the same rule and are not yet tested.
