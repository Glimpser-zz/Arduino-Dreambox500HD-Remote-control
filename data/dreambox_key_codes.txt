Dreambox DM500HD - IR key codes (reference)
============================================

Source: keymap table inside the kernel module dreambox_rc2.ko
Remote protocol: header frame 0x0B3F441A + key frame (see dreambox_autosend.ino)

Status:
  - Tested on the real box: code 32 (Menu)
  - Seen in captures of the original remote and matching this table: code 10 (Volume up), code 0 (Digit 0)
  - All other codes are read from the module table and are not yet tested
  - Any other code in the range 0-127 is empty in the module table and is not recognised
